# Contributing

Thanks for helping improve this list.

- One tool or resource per pull request, added to the section where it fits best, in a sensible position among similar entries.
- Use the official link and a short, neutral one-line description.
- Entries must help learners or teachers create, find, check, or read graded material, and must be actively maintained.
- Format: `- [Name](https://link) - Description.`
- Please explain in the pull request what the tool does and why it fits.
- No affiliate or tracking links, and no pirated books.
